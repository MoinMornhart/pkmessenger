Hey Joni! 👋 Moin hat grünes Licht gegeben: **Wir bauen die Android-App** 📱

**Wichtig vorweg:** Electron läuft leider **nicht auf Android** (gibt's dafür einfach nicht). Deshalb packe ich die **gleiche Oberfläche** in eine echte Android-App (APK).

**So wird's:**
- 📱 Gleiche Chats, Menüs, Einstellungen, Tour und Assistent, angepasst fürs Handy
- 🌍 Das Handy redet **direkt** mit Discord über deinen Bot, also **überall** (WLAN oder mobil), ohne PC und ohne IP
- 🔐 Token **verschlüsselt** im Handy-Schlüsselspeicher, übernehmbar per QR-Code vom PC
- 🤖 Gesendet wird wie immer **als Bot**, mit allen Schutzmaßnahmen (Link-Schutz, Sperrlisten, App-Passwort)
- 🏗 **Eigene CI:** GitHub baut die APK automatisch und hängt sie ans Release
- 🔄 **Auto-Update:** Die App findet neue Versionen selbst und fragt, ob sie installieren soll
- 🧪 Ich teste es mit Bildern in Handy-Größe

**Ehrlich gesagt:** Das ist ein großes Projekt, das baue ich in mehreren Schritten (jeweils als PR). **Sprachkanäle** kommen zuerst nur als „wer ist drin“, Sprechen auf dem Handy danach.
