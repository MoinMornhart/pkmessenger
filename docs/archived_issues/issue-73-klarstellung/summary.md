## Ursprüngliche Beschreibung
> ## Worum geht's?
> 
> Wunsch von MoinMornhart: Man soll **kein eigenes Discord-Konto** brauchen, um den Bot auf einen Server zu holen, das soll auch eine Admin des Servers machen können.
> ## So geht's jetzt
> 
>     * „Bot einladen“ (links in der Leiste oder im Einrichtungs-Assistenten) öffnet ein Fenster mit:
>       
>       * 📨 **fertiger Nachricht für die Admin** (mit Link und kurzer Anleitung) zum Kopieren und Weiterschicken
>       * 🔗 dem **Link** allein
>       * 📱 einem **QR-Code**, den die Admin direkt vom Bildschirm scannen kann
>       * ↗ „Selbst öffnen“, falls man selbst Admin ist
> 
>     * Die Admin öffnet den Link mit **ihrem** Konto, wählt den Server, klickt „Autorisieren“.
> 
>     * Sobald der Bot auf dem Server ist, schließt sich das Fenster von selbst.
> 
> 
> ## Gut zu wissen
> 
>     * Das ist Discords offizieller Weg (Bots kommen nur per Einladung auf Server). Die Admin braucht dafür das Recht „Server verwalten“.
> 
>     * Ein Discord-Konto braucht nur, wer den Bot **einmalig im Entwicklerportal anlegt**. Zum Benutzen und Einladen reicht der Bot-Token.
>
